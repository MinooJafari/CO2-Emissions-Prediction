This project uses **Linear Regression** to predict a vehicle’s CO₂ emissions based on three input features: the number of cylinders, engine displacement, and fuel consumption.

I developed a machine learning model that estimates the amount of CO₂ a vehicle produces based on its fuel consumption and other engine specifications. To evaluate the model’s performance, I tested it using data from a **Peugeot 206**, predicted its CO₂ emissions based on the three input features, and compared the predicted value with the actual emissions data to assess the model’s accuracy.
